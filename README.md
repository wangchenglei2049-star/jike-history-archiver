# jike-history-archiver

把即刻（Jike）个人主页的历史动态**全量**抓取为本地 JSON 文件的工具集，
附带一套「合并校验 → 结构化 → 导入 Notion」的完整归档流程。

网页端逐条翻历史动态慢且容易漏。这套工具走即刻 Web 端自己用的接口，
按页批量拉取：一个发了上万条动态的账号，全量抓取也只需要十几分钟。

## 组成

| 部分 | 作用 |
| --- | --- |
| `extension/` | 浏览器扩展（Chrome / Edge，MV3）：在个人主页点一下就开始抓，断点续跑，抓完自动下载 JSON。**只负责下载。** |
| `jike-fetch.js` | 控制台脚本版：不装扩展时，在即刻主页的浏览器控制台粘贴运行，功能相同。 |
| `docs/WORKFLOW.md` | 完整归档流程：多段文件合并与校验口径、转结构化数据的字段约定、导入 Notion 的方法与坑。 |

## 原理

即刻 Web 版用 REST 接口加载个人动态流：

- `POST https://api.ruguoapp.com/1.0/personalUpdate/single`
- 请求头带 `x-jike-access-token`，令牌就是页面 `localStorage` 里的
  `JK_ACCESS_TOKEN`（你登录后浏览器自己生成的）
- 请求体 `{username, limit, loadMoreKey}`，响应的 `loadMoreKey` 是下一页游标

工具在你已登录的浏览器页面里运行：每页现读令牌、按 2.5 秒/页的节奏
拉取，直到没有更旧的帖子为止。令牌约 20–25 分钟过期，过期后刷新页面
续跑即可（扩展和脚本都支持断点续跑）。

## 快速开始（扩展）

1. 下载本仓库，解压。
2. 打开 `chrome://extensions`，开启「开发者模式」。
3. 「加载已解压的扩展程序」，选择 `extension/` 文件夹（装好后别删它）。
4. 打开自己的即刻个人主页，点扩展图标 →「开始 / 续跑」。
5. 抓完自动下载 `jike-seg-done-*.json`；中途令牌过期会先下载本段，
   刷新页面再点一次即可续跑。

不装扩展的话，打开 `jike-fetch.js`，按文件头注释改好配置（或留空让它
从当前页面 URL 自动识别账号），整段粘贴进即刻主页的控制台运行。

## 隐私与安全

- 工具只在你自己的浏览器里运行，**令牌不经过任何第三方服务器**，
  代码里没有上报、统计或外发请求。
- 只读你自己主页的动态流接口，不点赞、不评论、不发帖。
- 抓到的 JSON 只下载到你本地，之后如何归档（例如导入 Notion）由你决定，
  方法见 `docs/WORKFLOW.md`。

## 注意

- 节奏请勿调快：2.5 秒/页是刻意的，过快请求有触发限流/风控的风险。
- 接口是即刻 Web 端的未公开接口，将来可能变更；若返回 404，
  在页面开发者工具的网络面板里找 `personalUpdate` 请求对照修正。
- 本项目与即刻官方无关，仅供个人备份自己的数据使用。
