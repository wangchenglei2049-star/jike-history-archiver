# 即刻历史抓取扩展

把即刻个人主页的历史动态一键抓成 JSON 文件。原理见仓库根目录 README，
抓完之后的合并、校验与导入 Notion 流程见 `docs/WORKFLOW.md`。

## 安装（Chrome / Edge，开发者模式加载）

1. 解压/克隆本仓库，把 `extension/` 文件夹放在一个固定位置
   （别删，浏览器会一直引用它）。
2. 地址栏打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择 `extension/` 文件夹。
4. 工具栏出现「即刻历史抓取」即装好（可点图钉固定）。

## 使用

1. 打开自己的即刻个人主页（已登录状态）。
2. 点扩展图标：
   - 「只抓比这个 Post ID 更旧的」留空 = 从最新开始全量抓；
     补抓某段时填上界 Post ID，只收更旧的。
   - 每页间隔默认 2500ms，不要调到 1000 以下。
3. 点「开始 / 续跑」。弹窗显示进度（条数/页数）；关掉弹窗不影响抓取，
   再打开能继续看进度。
4. 令牌约 20–25 分钟过期一次，出错提示 401 时：本段文件已自动下载，
   刷新页面后重新点「开始 / 续跑」会从存档断点继续（已抓帖子也在
   存档里，不会丢、不会重复计数）。
5. 显示「已到历史尽头」即全量完成，文件自动下载为 `jike-seg-done-*.json`。

## 注意

- 抓取中不要关掉即刻标签页（可以切到别的标签页用）。
- 「清进度」会删掉扩展里存的断点和已抓帖子，点之前先确认已下载的
  段文件在手里。
- 本扩展只读你自己主页的接口，不点赞、不评论、不发帖；
  令牌只在页面本地使用，不经过任何第三方服务器。
